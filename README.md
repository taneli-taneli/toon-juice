# Toon Juice

A small animated cartoon archive built with plain HTML, CSS, and JavaScript.

## Project structure

- `index.html` — main app entry point
- `script.js` — loads `shows.json` and renders the gallery
- `shows.json` — source data for the cartoon catalog
- `style.css` — site styling
- `*.jpeg` — image assets used by the catalog

## Notes

The `dp-fetch-json/` folder is a legacy duplicate kept for reference. The live app runs from the repository root.
